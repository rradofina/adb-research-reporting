# PSDQ Bangladesh Facility-Validation Evidence Ladder

attestation_chain: ai-first

This note summarizes the no-contact evidence ladder for the Bangladesh PSDQ
facility-validation chain. It is a reader-navigation artifact: it helps a
reviewer follow how the analysis moves from source-disagreement strata to the
human/source-owner wall. It is not a new validation result.

The ladder is generated by
`scripts/build-bgd-facility-evidence-ladder.py`, which reads committed summary
JSON files and writes:

- `generated/psdq-bgd-facility-validation-evidence-ladder.csv`
- `generated/psdq-bgd-facility-validation-evidence-ladder-summary.json`

## How to Read It

The ladder clarifies the evidence spine behind the showcase page:

1. The source-disagreement strata show where registry-map disagreement is
   concentrated.
2. The validation sample and coded screen make the facility-row review
   reproducible.
3. The public-map and public-source passes attach public evidence while keeping
   unresolved rows open.
4. The human-gated handoff, worksheet, and AI closure audit make the stopping
   rule explicit: current public evidence cannot close, reclassify, correct, or
   use map-absence language for the terminal rows without source-owner or human
   validation evidence.

## Non-Claim

This is an AI-first no-contact evidence ladder for the PSDQ Bangladesh
facility-validation chain. It summarizes committed summary artifacts so a
reader can follow the audit sequence. It is not external outreach, not human
validation, not ground truth, not a row closure, not a same-facility
reclassification, not a coordinate correction, not a facility-quality
assessment, and not a service-access estimate.
