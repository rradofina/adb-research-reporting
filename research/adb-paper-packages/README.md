# ADB-Facing Paper Packages

`attestation_chain: ai-first`

These are ADB/ERDI-style package notes. They are not final papers. Each
file forces the problem statement, key messages, evidence spine, chart plan,
caveat box, policy-use paragraph, and source notes to exist before prose is
expanded into an ADB Brief, working paper, methods note, or dataset note.

Use `.claude/skills/adb-erdi-paper-framing.md` when updating this folder.
Use `research/originality-register.md` to keep novelty claims narrow.

## Rule

Do not present all topics as equally finished. Present these packages as:

1. one computed measurement-gap package,
2. one poverty/small-area data-integration package,
3. one road-quality/access package,
4. a transparent queue of additional granular public-data upgrades.
