# Upgrade gap — what would make recovery measurable?

`attestation_chain: ai-first`

The next step is not another threshold sweep. It is a better evidence object:

1. hazard or damage footprints verified against event-specific sources;
2. a longer pre-event baseline with denser valid observations;
3. settlement-aware aggregation that avoids dark, uninhabited centroid area;
4. comparison areas or a defensible event-study design;
5. independent outcomes such as electricity restoration, facility operation,
   school reopening, firm activity, or household recovery; and
6. event-specific validation before any cross-economy scaling.

Database-backed storage becomes valuable when this pipeline expands beyond a
single committed case: store event, geometry version, raster item, observation,
quality mask, specification, and result as normalized tables or partitioned
Parquet. The current repository remains appropriate for frozen source ledgers,
scripts, small evidence tables, and public artifacts; full rasters belong in
object storage, not Git or Vercel bundles.
