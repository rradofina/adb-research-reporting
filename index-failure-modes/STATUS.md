# Robust and wrong at the same time — operating status

`attestation_chain: ai-first` · Last updated: 2026-08-05

- **Finding:** In five programs the ±50% parameter suite certified a leading set
  as stable and a later construct check rejected that same set — 5 of 5, with
  the certified and tested sets verified identical in four. Parameter
  robustness carries no information about construct validity.
- **Why it exists:** Twelve programs each reported "our proxy failed" as a
  separate result. That is one finding restated twelve times and no reader has
  a stake in it. The failures are the sample, not the confession.
- **Literature check (2026-08-05):** Deflationary and recorded in the panel.
  The denominator result and the construct-overlap tally are settled method
  (SIDS vulnerability literature; Ravallion 2012). The degenerate sweep is a
  known method error implemented locally in one program. Only the
  robustness-versus-validity pairing is an open candidate.
- **Stage:** Panel, results, and literature position built from committed
  artifacts. No pre-registration, no hero visual, no public surface.
- **Maturity:** Unlabeled and not on the public site. Promotion needs
  `pre-registration.md`, a hero visual, and the five research gates.
- **Input boundary:** Reads only this repository's committed generated
  artifacts. Measures nothing about any economy directly.
- **Sample boundary:** Five paired cases is a demonstration, not a rate. Twelve
  tests this lab ran on orderings this lab built; not a random sample of
  published indices.
