# Topic Sprints

`attestation_chain: ai-first`

This folder stores L2 new-topic sprints before they become full research
programs.

Rules:

- Sprints are exploratory and do not create public claims.
- Every sprint needs a committed script, generated table or chart, source
  sanity note, visual QA, and a promote/defer decision.
- Strong sprints may become program prospectus candidates.
- Weak sprints stay here as negative selection evidence.
