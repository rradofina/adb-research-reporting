# PSDQ reproducibility guide

Last updated: 2026-06-19.

This guide is the single runbook for reproducing the current
`public-service-data-quality` package. It connects the source caches, pipeline
scripts, generated outputs, public evidence sync, and gates. The broader
research-factory process lives in `research/factory.md`; the current status and
blockers live in `research/STATUS.md`. The owner/source handoff and completed
PSA manual-download record live in `SOURCE-ACTION.md`.

## Current reproducibility status

The current PSDQ package is reproducible from the scripts and existing public
caches in this repository. The previous PSA SAE source-access blocker was
resolved on 2026-05-05 when the owner manually downloaded the official
workbook and Codex seeded the canonical cache.

- Philippines and Bangladesh ADM1 registry-vs-OSM outputs are generated from
  cached registry pages and the existing `luminosity-gap` access-services OSM
  artifact.
- Bangladesh Open Buildings facility-buffer, upazila exposure, and road-context
  outputs are generated by the Python drivers in `scripts/`.
- The Bangladesh source-disagreement L3 strata artifact is a no-network
  packaging pass over the generated exposure and road-context outputs.
- The Bangladesh facility-validation sample is a no-network design pass over
  the L3 strata, exposure-ranked table, and DGHS facility-coordinate extract.
  It produces a blank coding sheet, not validation outcomes.
- The Bangladesh facility-validation coded screen is a no-network public-source
  screen over the blank coding sheet, the existing all-Bangladesh OSM
  health-feature cache, and geoBoundaries ADM3. It is automated triage, not
  manual validation.
- The Bangladesh AI public-source review ledger is a no-network second pass
  over the coded screen and OSM candidate table. It separates flagged rows into
  public-map-gap, coordinate-repair, name/type-resolution, and nearby-OSM
  workstreams. It is not human validation.
- The Bangladesh coordinate-repair triage is a no-network pass over the
  coordinate-repair subset, public geoBoundaries ADM3, cached OSM health
  features, and cached DGHS public rows. It separates missing coordinates,
  reused coordinates, wrong-admin coordinates, and public-boundary mismatches.
  It is not human validation.
- The Bangladesh public-map-gap triage is a no-network pass over the
  public-map-gap subset after coordinate screening. It keeps all 40 rows open
  while separating duplicate-coordinate, same-upazila name-signal,
  buffer-sensitivity, zero-OSM-upazila, OSM-present-not-at-facility, and
  no-nearby-OSM lanes. It is not human validation.
- The Bangladesh public-map-gap row-evidence pass is a no-network pass over the
  public-map-gap triage CSV/JSON. It attaches DGHS source notes, public profile
  URLs, OSM coordinate-inspection URLs, OSM feature or absence notes, and
  keep-open reviewer actions for all 40 map-gap rows. It is not row closure or
  human validation.
- Philippines ADM3 Open Buildings, NHFR code-resolution, and OSM-health context
  outputs are generated by the Python drivers in `scripts/`.
- Philippines poverty context now uses the owner-manually downloaded official
  PSA 2023 city/municipality SAE Excel at
  `public-service-data-quality/.cache/psa-phl-2023-sae-with-psgc-nohuc.xlsx`,
  plus PSA OpenSTAT direct estimates for HUC/direct-estimate rows.

No missing poverty value is imputed. Missing rows are explicitly marked
`no_poverty_table_match` when the official SAE workbook is present.

## Environment

Run commands from the repository root.

Required for the site and gates:

```bash
node --version
npm --version
```

Required for the PSDQ Python pipelines:

```bash
python --version
```

The lightweight poverty-context path uses `pandas`, `requests`, and `openpyxl`
when the Excel source is present. The full Open Buildings and road-context
paths also use `numpy`, `shapely`, `pyogrio`, `geopandas`, and `scikit-learn`.

## Minimal current poverty-context rerun

This reproduces the current Philippines poverty overlay.

```bash
python public-service-data-quality/scripts/fetch-phl-sae-poverty.py
python public-service-data-quality/scripts/build-phl-admin3-poverty-context.py
```

Expected current status with the owner-downloaded official PSA SAE Excel:

- `generated/psdq-phl-admin3-poverty-context.csv`
- `generated/psdq-phl-admin3-poverty-context-summary.json`
- `status = sae_city_municipal_join`
- `rows_with_openstat_direct_poverty = 35`
- `rows_with_sae_poverty = 1597`
- `rows_without_poverty = 10`

To enforce the full-SAE requirement in a future run:

```bash
python public-service-data-quality/scripts/fetch-phl-sae-poverty.py --require-sae
python public-service-data-quality/scripts/build-phl-admin3-poverty-context.py --require-sae
```

Those commands should pass while the owner-downloaded official PSA SAE Excel is
available at the documented cache path.

To refresh or reseed the full join after a normal-browser download from the PSA
page, seed the deterministic cache with the official workbook:

```bash
python public-service-data-quality/scripts/fetch-phl-sae-poverty.py --sae-xlsx <downloaded-xlsx>
python public-service-data-quality/scripts/build-phl-admin3-poverty-context.py --require-sae
```

The fetcher validates that the supplied file is an XLSX payload before copying
it to `.cache/psa-phl-2023-sae-with-psgc-nohuc.xlsx`.

## Bangladesh facility-validation coordinate-repair triage

This step does not fetch data and does not validate facilities. It reads the

checks exact-coordinate reuse across the sampled DGHS rows, and measures the
nearest cached OSM health feature to each suspect coordinate.

```bash
python public-service-data-quality/scripts/triage-bgd-facility-coordinate-repairs.py
```

Expected outputs:

- `generated/psdq-bgd-facility-validation-coordinate-repair.csv`

## Bangladesh facility-validation public-map-gap triage

duplicate coordinates, same-upazila name signals, 500m-to-1km buffer
sensitivity, zero-OSM upazilas, and no-nearby same-upazila OSM signals.


Expected outputs:

inspection URL, nearest or best same-upazila OSM health evidence where
available, and a keep-open reviewer action.

```bash

```

Expected outputs:

- `generated/psdq-bgd-facility-validation-public-map-gap-evidence.csv`
