# Conclusion and next evidence upgrade

`attestation_chain: ai-first`

The inherited imports × LPI ranking is retired. Only one of its five named
economies remains in the main observed port-time diagnostic, overlap stays
between zero and two across 20 specifications, and the strongest association
runs opposite the label.

This is a useful negative result. It prevents a stable national formula from
being mistaken for a validated port or corridor measure and redirects the
analysis toward the unit where friction actually occurs. CPPI provides the
port-side object; it does not complete the journey inland.

The next evidence upgrade is a reproducible join of the official World Bank
LPI 2.0 shipment file to the CPPI port layer, preserving route, vintage,
sample, and coverage limits. Until that named file is available, the honest
finished product is the construct failure with an explicit open hinterland
gate—not another national proxy.
