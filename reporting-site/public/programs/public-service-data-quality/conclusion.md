# Conclusion and next evidence upgrade

`attestation_chain: ai-first`

The practical conclusion is straightforward: a public health-facility map
should be source-checked before it becomes an access model. In the two public
data pilots, OpenStreetMap counts equal 17.1% of the Philippine official
clinical-tier registry and 11.8% of the Bangladesh registry. Completed
sensitivity and leave-one-out tests keep both results far below count parity,
while the subnational maps show that the disagreement is not spatially
uniform.

This changes the order of work for analysts. First compare the map and the
official registry, disclose where each source is missing, and resolve only the
facility identities supported by public evidence. Then—and only then—build
catchments, travel-time surfaces, or service-coverage estimates.

The highest-value upgrade is not another automated portal scan. It is an
independent, facility-level validation source with identity and location
evidence, followed by a district or catchment analysis using a pinned map
snapshot. Human-final standing additionally requires the owner-only review
path in `CONSTITUTION.md` §18.5. Until those upgrades exist, the bounded
source-disagreement finding is the finished current-issue result.
